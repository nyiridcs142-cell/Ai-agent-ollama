# Python programming step by step

1. Write code in a file using `[FILE: name.py]` followed by a ```python code block.
2. If an external package is required, check whether it is installed with `[MODULE: package_name]`. If it is missing, suggest `[COMMAND: pip install package_name]`.
3. Run it with `[COMMAND: python name.py]`.
4. When an error occurs, read the last line of the error message, fix the code, and write it again using the same filename.

Rules:
- Always write complete, runnable code instead of fragments.
- Use one code block per file.
- Do not delete files or use system commands unless explicitly requested.
